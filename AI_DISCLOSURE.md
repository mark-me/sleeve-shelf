# AI Usage Disclosure

## Overview

This project was developed with assistance from AI tools,
including Claude by Anthropic.

## How AI Was Used

Claude assisted with selected aspects of the development process:

- Generating and refining code
- Debugging and troubleshooting
- Exploring implementation approaches
- Refactoring existing code
- Technical documentation

## Human Responsibility

AI-generated suggestions were reviewed before being incorporated
into the project.

The project maintainer is responsible for the final code,
architectural decisions, testing, and maintenance.

## Transparency

AI assistance is disclosed to make the development process
transparent to users, contributors, and reviewers.
