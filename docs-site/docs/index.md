# Sleeve & Shelf

Documentation for **Sleeve & Shelf**, a self-hosted web application that organizes a vinyl record collection across physical storage, based on musical kinship, artist era, and available shelf space.

This site is still a placeholder — content will be added here as the project develops. In the meantime, see the [requirements document](https://github.com/mark-me/sleeve-shelf/blob/main/docs/requirements.md) in the repository.
